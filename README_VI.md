mangadex-dl-dreamme

Phiên bản được tùy chỉnh và phát triển dựa trên mangadex-dl, dùng để tải manga từ MangaDex.

Dự án giữ cách sử dụng đơn giản bằng terminal của bản gốc và bổ sung một số thay đổi phục vụ nhu cầu sử dụng cá nhân.

Tính năng

- Tải manga từ MangaDex
- Chọn ngôn ngữ và nhóm dịch
- Chọn chapter cần tải
- Đóng gói CBZ
- Hỗ trợ Windows & Termux
- Giao diện terminal đơn giản

Cài đặt

Windows
```
git clone https://github.com/Akeni-NK/mangadex-dl-dreamme.git
cd mangadex-dl-dreamme
pip install requests
python mangadex-dl.py
```
Termux 
```
pkg update
pkg install python
pip install requests
git clone https://github.com/Akeni-NK/mangadex-dl-dreamme.git
cd mangadex-dl-dreamme
python mangadex-dl.py
```
