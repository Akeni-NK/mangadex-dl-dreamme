mangadex-dl-dreamme

A modified version of mangadex-dl for downloading manga from MangaDex.

This fork adds improvements and personal modifications while keeping the original project's simple terminal-based workflow.

Features

- Download manga from MangaDex
- Select language and translation group
- Select chapters to download
- CBZ packaging
- Windows & Termux support
- Simple terminal interface

Installation

Windows

git clone https://github.com/Akeni-NK/mangadex-dl-dreamme.git
cd mangadex-dl-dreamme
pip install requests
python mangadex-dl.py

Termux

pkg update
pkg install python
pip install requests
git clone https://github.com/Akeni-NK/mangadex-dl-dreamme.git
cd mangadex-dl-dreamme
python mangadex-dl.py
